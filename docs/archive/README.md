# Архив документации «Контура»

Этот каталог содержит исторические продуктовые направления, старые state/nav/backlog snapshots, V1–V5 спецификации, исследования и handoff-доказательства.

## Жёсткое правило

**Ни один файл из `docs/archive/` не является текущим ТЗ.**

Исторический документ можно использовать только для:
- provenance/forensic;
- объяснения происхождения кода;
- восстановления старого решения;
- проверки, почему конкретная таблица/route/file существует.

Он НЕ может автоматически вернуть старую механику в текущий продукт.

Текущий продукт описан в корневом `CURRENT_PRODUCT.md`.

## Почему архив существует

В репозитории накопились несколько эпох V1–V5 и продуктовые эксперименты. Из-за этого агенты и люди легко делали ложный вывод «последний номер версии = текущий продукт» или «код существует = фича одобрена». Cleanup сохраняет историю, но отделяет её от актуального source of truth.

## Категории

- `legacy/` — старые top-level документы, которые раньше могли ошибочно восприниматься как authority;
- остальные исторические docs будут переноситься сюда после пофайловой классификации;
- runtime-код не переносится сюда вслепую: сначала нужен reachability/provenance gate.

## Не удалять доказательства без причины

Архив — не корзина. Файлы здесь могут понадобиться для exact recovery. Физическое удаление допустимо только после доказанного дублирования/непригодности и отдельного cleanup-решения.
