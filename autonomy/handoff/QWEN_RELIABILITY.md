Что уже есть и сохраняется:
- локальные CAPTCHA/rate limit/expired auth не останавливают весь пул: бюджет переключений задаётся `QWEN_ACCOUNT_FAILOVER_BUDGET`, по умолчанию 4, жёсткий потолок 6;
- provider-wide WAF/trust restriction, provider pressure и неоднозначный timeout по-прежнему останавливают дальнейшее прощупывание соседних аккаунтов;
- tool-loop хранит связь `chatId` с аккаунтом-владельцем; при смене аккаунта создаётся свежий Qwen-тред и один раз переносится полная локальная история;
- OpenCode checkpoint переживает повреждение основного session JSON через атомарную запись и backup;
- агент продолжает после tool result и после ошибок инструмента; обычный лимит — 12 модельных ходов, жёсткий потолок — 24;
- два режима системного промпта (`engineer`/`owner`) уже есть;
- runtime/profile recovery не передаёт GPG-ключ через argv и не печатает секреты;
- `provider-circuit.json` и account JSON сохраняются crash-safe; запись account store уже доказана на Linux и Windows;
- ChatGPT relay не считать активной задачей до появления owner session или явного owner-запроса; outbox не включать.

Новый найденный пробел надёжности:
- `src/session-store.js` атомарно и с `fsync` пишет основной `opencode-sessions.json`, но backup после этого обновляет обычным `copyFileSync(FILE, BACKUP_FILE)`. Если процесс/машина оборвётся именно во время обновления backup, основной файл останется целым, но резервная копия может стать частичной. При более позднем повреждении primary восстановление уже не гарантировано;
- минимальное независимое исправление: обновлять backup тем же crash-safe способом — уникальный backup temp → запись/копирование → `fsync` → атомарный rename, с очисткой temp; расширить `session-store-restart-test.js` проверкой отсутствия backup-temp хвостов и восстановления из последней целой резервной копии;
- перед записью снова проверить свежий head: другой Qwen-рабочий сейчас менял `server.js`/continuation test, а `src/session-store.js` в последних трёх коммитах не затрагивался. Не лезть в `server.js`, чтобы не конфликтовать.
