# Идея: внешний агентный relay без простоя ChatGPT Tasks

Не внедрять прямо сейчас ценой остановки Qwen/Notion/Kontur. Этот файл сохраняет архитектурную идею владельца, чтобы к ней вернуться после ближайших продуктовых задач.

## Проблема
ChatGPT Scheduled Tasks на Plus дают 5 активных задач и каждая может автоматически стартовать не чаще раза в час. Если один запуск полезно работает только 5–10 минут, перестановка времени не создаёт больше пяти стартов в час.

## Идея
Считать ChatGPT Tasks коротким «пульсом управления», а длительную работу переносить во внешний уже оплаченный/бесплатный исполнитель.

Схема:
1. ChatGPT Task читает `OWNER_INTENT_RU.md`, `CURRENT_RU.md`, свежий handoff и GitHub.
2. Если работа короткая — делает её сама.
3. Если нужна долгая агентная разработка — пишет в GitHub маленький `job` с проектом, точным ref, задачей и ожидаемым результатом.
4. Уже подключённый CircleCI забирает job и на отдельной служебной ветке/рабочей папке клонирует нужный проект.
5. Внутри CircleCI запускается наш Qwen- или позже Notion-agent с реальными локальными инструментами (файлы, shell, тесты, браузер), который может работать дольше одного ChatGPT-запуска.
6. Агент пишет изменения в отдельную ветку/PR и оставляет короткий result/handoff в GitHub.
7. Следующий ChatGPT Task читает результат, проверяет его и либо принимает следующий шаг, либо запускает продолжение.

## Токены
Не использовать ChatGPT web-session/access token и не автоматизировать закрытые внутренние ChatGPT endpoints. Для записи результата достаточно отдельного минимально-правного GitHub token / GitHub App credential в CircleCI secret/context. Уже существующий Qwen CircleCI умеет безопасно писать callback в GitHub через скрытый `AUTOPILOT_HANDOFF_TOKEN`; перед расширением его прав сначала проверить фактические permissions без вывода секрета.

Qwen/Notion runtime credentials тоже должны жить только в secret storage внешнего исполнителя и не попадать в argv/log/artifacts.

## Почему это лучше
- пять ChatGPT Tasks остаются бесплатным/включённым управляющим пульсом;
- CircleCI выполняет длительные вычисления;
- Qwen/Notion становятся «мозгом» длинной coding-agent работы без OpenAI API credits;
- GitHub — постоянная память и очередь;
- телефон позже может быть только пультом.

## Work/Codex
Не рассчитывать на ChatGPT Work как на способ обойти расход Codex: по текущей официальной модели OpenAI Work и Codex на Plus/Pro используют общий agentic usage/credits. Work можно изучить как удобный интерфейс, но не как бесплатный бесконечный compute.
