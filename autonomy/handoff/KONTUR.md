## Ближайшая работа

GitHub Actions minutes уже закончились. Не строить следующий визуальный прогон на GitHub Actions.

На текущей продуктовой линии PR #12 нужно собрать CircleCI-based браузерный пользовательский прогон. Сейчас в `apps/miniapp/package.json` нет Playwright/Puppeteer, то есть полноценного автоматического браузерного прохода в репозитории пока нет.

Желаемый прогон:
- поднять exact-head Mini App локально внутри CircleCI;
- Chromium/Playwright проходит приложение как реальный пользователь, а не проверяет строки исходника;
- пройти основные стадии бота/Mini App от стартового экрана до результата/коллекции настолько полно, насколько позволяет тестовое окружение;
- отдельно q8 с быстрым и медленным ответом;
- мобильные размеры 320x568 и 430x1000;
- reduced-motion и skip;
- ловить console errors, page errors, failed requests, неожиданные 4xx/5xx, зависшие переходы и грубые задержки;
- на ключевых шагах делать screenshot, а на главном happy path video/trace;
- затем тем же сценарием проверить изолированный staging и Telegram WebView-подобное окружение/Telegram API mock;
- результаты и визуальные артефакты должны быть доступны следующему ChatGPT-запуску без GitHub Actions. Можно использовать CircleCI artifacts + безопасную ссылку/метаданные, либо существующий Cloudflare/R2/другой уже подключённый бесплатный канал. Не заводить платный сервис ради этого.

После первого зелёного технического прохода не объявлять продукт готовым: просмотреть реальные кадры, сверить с ТЗ/перепиской/замечаниями и исправить визуальные/UX-недоделки.
