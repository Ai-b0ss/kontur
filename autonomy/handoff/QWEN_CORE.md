- Исправлен OpenCode streaming checkpoint. `chatId/accountId` больше не сохраняются только по факту `response.status=true`: сначала SSE должен закончиться пригодным ответом. При `retryEmpty` новый route держится только в памяти и фиксируется после принятого потока.

- Усилена поздняя CAPTCHA-ротация. По умолчанию разрешено до 2 таких восстановлений, жёсткий потолок — 4.

Они требуют отложенный streaming checkpoint, сохранение последнего исправного checkpoint, совпадение аккаунта создания треда с аккаунтом запроса и продолжение после поздней CAPTCHA на здоровом аккаунте.
