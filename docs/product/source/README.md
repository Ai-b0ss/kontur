## Fail-closed правило импорта

Импорт считается доказанным только когда для каждого файла зафиксированы:

- исходный объект/архив, из которого получены байты;
- размер в байтах;
- SHA-256 exact bytes;
- отсутствие нормализации CRLF/LF при переносе;
- Git blob SHA после записи;
- проверка, что Git checkout даёт тот же SHA-256.

Пока эти поля не доказаны, производные `PRODUCT_BRIEF_2026-08-13.md` и `DECISION_LOG_2026-08-14.md` остаются удобной канонической интерпретацией, но **не заменяют первичник**.
