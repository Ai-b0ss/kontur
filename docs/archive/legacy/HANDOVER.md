## Что сейчас реализовано

Текущий production сохраняет V1–V3 и добавляет открытый для корректно
авторизованных участников основного чата V4 «Нулевой сезон»:

1. `/start` и тест из восьми вопросов.
2. Одна из пяти ролей-птиц.
3. `/worm` reply-командой в разрешённом чате.
4. Раздельные репутация и расходуемый кошелёк.
5. Пассивные червяки, яйца, коллекция и экипировка окрасов.
6. Недельная стая/рейтинг.
7. Минимальный мост к реальным действиям: оператор подтверждает событие,
   выполненный кейс или проект после ревью; игрок получает signal-карту и
   одно золотое перо.
8. Обезличенный отчёт пилота: воронка, D1/D7, активность, червяки и
   signal-карты.
9. Пять разделов Mini App: птица, стая, действия, гнездо и коллекция.
10. Восемь равных входов: спросить, помочь, найти связь, сориентироваться,
    найти возможность, внести вклад, сохранить и увидеть прогресс.
11. V4: претест, выбор одной активной птицы на сезон, одна серверно
    проверяемая серия из пяти вопросов в игровые сутки, общая ветвь, яйца,
    анонимные прогнозы и добровольный полёт 4–6 с общей фиксированной целью.

`DESIGN.md` и `kontur-brief.html` сохранены как расширенная концепция, но не
являются описанием уже реализованного объёма. Сезоны, ветки развития,
пользовательская загрузка доказательств и веб-админка не возвращались.

## Быстрый старт

Требуется Node.js 22+ и pnpm, соответствующий lock-файлу.

```powershell
pnpm install --frozen-lockfile
Copy-Item .env.example .env
# вручную заполнить .env; не пересылать его обратно в архиве
pnpm check
pnpm dev
```

На Windows lockfile содержит отдельные нативные пакеты для Vite, `tsx` и
Rollup. Не удаляйте их из manifest как «лишние»: они обходят пропуск optional
dependencies в pnpm и нужны для воспроизводимой сборки.

Mini App: `http://127.0.0.1:5173/`

API: `http://127.0.0.1:8787/`

Повторяемый Cloudflare OAuth-вход на Windows. Скрипт временно проксирует
жёстко заданный Wrangler callback `localhost:8976` в IPv4 listener на `8977`
и всегда убирает локальный мост после завершения:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass `
  -File tools/cloudflare-login.ps1

pwsh -NoProfile -ExecutionPolicy Bypass `
  -File tools/cloudflare-deploy.ps1 `
  -ProxyUrl http://127.0.0.1:7890
```

`-ProxyUrl` нужен только когда CLI не проходит через TUN/Fake-IP автоматически;
в данном окружении это локальный mixed-port FLClashX.

Перед изменением схемы или логики снимите production backup:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass `
  -File tools/cloudflare-d1-backup.ps1 `
  -ProxyUrl http://127.0.0.1:7890

# Dry Run точки Time Travel; реальное действие требует отдельного -Apply
pwsh -NoProfile -ExecutionPolicy Bypass `
  -File tools/cloudflare-d1-restore.ps1 `
  -Timestamp "2026-08-06T01:28:00Z" `
  -ProxyUrl http://127.0.0.1:7890
```

`backups/` содержит персональные данные, не входит в Git и handoff.

Для отдельного тестового бота используйте `.env.telegram-test.example` как
шаблон и задавайте путь через `KONTUR_ENV_FILE`. Обычный `.env` при этом не
переименовывайте.

## Операторская выдача золотого пера

Сначала Dry Run:

```powershell
pnpm signal:issue -- --username nick --kind own_project `
  --title "Проект прошёл ревью" --key project-2026-001
```

После проверки игрока, типа, названия и стабильного ключа повторите команду с
`--apply`. Один и тот же ключ не создаёт вторую карточку.

Если одинаковый username принадлежит нескольким сохранённым игрокам, CLI
останавливается. В этом случае используйте однозначный `--tg-id`.

## Перед открытием пилота

1. Открыть V4 из меню бота, пройти претест, выбрать птицу и завершить одну
   серию; убедиться, что второй ход этого дня не принимается.
2. Взять одно яйцо прогнозом на другую птицу и собрать четыре человека на ту
   же цель полёта; после ночного cron проверить только агрегированную сводку.
3. При аварии выключить V4 командой из `README.md`; V1–V3 останутся отдельно.
