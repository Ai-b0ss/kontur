- Фон графит `#141414`, не тёмно-зелёный лес.
- Интерфейсный акцент cyan `#5AC8D5` (действие / выбранное место).

- Фирменный фиолетовый ЦУ `#7659FF` **не** главный цвет Контура.
- Шрифты: Manrope (display) + Inter (body). Без serif в Mini App v1.
- Композиция: один герой на экран; карточки только для взаимодействия.
- Птица: позже органическая редакционная иллюстрация (не V5 poly, не стикер).
- Дерево: позже SVG с 7 узлами на ветвях (не ряд квадратов-слотов).
