## Что делает этот этап

Production меню (`?season=zero`) становится **витриной ядра**:

1. Онбординг / претест → птица (понятно глазами через классический `Bird`).
2. Lesson из трёх шагов (птица, `/worm`, один ход) + replay «Как это работает».
3. Домашний экран (Variant B): птица-герой → «Сегодня у тебя один ход» →
   один CTA (+ intents) → компактное дерево из 7 мест → спокойная строка
   ресурсов `жетоны · червяки` → прогноз/команда в подробностях.
4. Серия ~75 сек и эффект на ветви — без админской панели.
5. V5 не удаляем и не мешаем в этот URL.

`/api/v4/state` отдаёт опциональный объект `core` из классических `profiles` +
`wallets` (+ `colorings`) и флаг `actionTaken` за текущий gameDay, без новой миграции.
