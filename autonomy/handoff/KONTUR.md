Продуктовая линия: PR #12, ветка `fix/kontur-core-visual-continuity-20260818`, текущий head `28272f30468b53b6698a64615283c8f7c6d110a7`. PR остаётся draft и mergeable. Production/main/prod D1 не трогались. GitHub Actions не запускались.

CircleCI-исполнитель живёт отдельно в `Ai-b0ss/qwen-free-api`, ветка `autopilot/kontur-browser-qa-v2-20260819`. Текущий runner head после этого запуска: `e03ebb4e23b7b5c527a7336d402eea990628defc`. Он по-прежнему клонирует exact private Kontur SHA через временный HTTP auth header, не печатая токен и не меняя Qwen-продукт.

В старом браузерном сценарии нашлась ошибка именно теста: кадры `q1/q4/q8` снимались уже после клика, поэтому могли фактически показывать следующий вопрос. Кроме того, полный путь всегда запускался с `?community=1`, то есть не доказывал настоящий default entry. Добавлен новый `scripts/kontur-browser-qa-v3.mjs`: все три главных сценария теперь идут через реальный `/ -> hook -> q1..q8 -> hatch/reveal -> /worm -> Home -> reward egg -> equip`, а обязательные кадры снимаются ДО ответа на соответствующем вопросе.

Новый прогон проверяет:
- `320x568` с быстрым q8;
- `430x1000` с искусственно медленным q8 и `skip animation`;
- `320x568` с `reduced-motion`;
- на медленном q8 отдельно доказывает, что hatch не стартует до готовности API;
- console/page/request errors, неожиданные API, горизонтальный overflow, CLS/layout shift;
- сохраняет exact-review кадры `01-hook`, `02-hook-start-before`, `03-quiz-q1`, `04-quiz-q4`, `05-quiz-q8`, ожидание slow API, hatching, `06-bird-reveal`, `07-worm-loop`, `08-home`, reward/equip; плюс video, trace и JSON.

CircleCI-конфиг теперь запускает полный journey даже если отдельный default-hook smoke упал, чтобы при дефекте не терять остальные артефакты. В доступном GitHub status API CircleCI-статус этого runner commit пока не отображается, поэтому PASS/FAIL не выдумывать и production не трогать.

Отдельно при чтении owner live-review подтверждён важный визуальный риск, который надо оценить по кадрам: текущий hatch CSS всё ещё режет три полные копии `egg-stage-08.webp` через крупные `clip-path: polygon(...)`. Это технически очень похоже на запрещённый владельцем «взрыв геометрических кусков». Не править вслепую до просмотра Chromium-кадров; если артефакты подтверждают проблему — следующий продуктовый фикс должен сделать скорлупу естественными читаемыми кусками и показать птицу раньше, сохранив одну сцену.
