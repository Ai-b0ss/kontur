# Первый заход · экранный сценарий «Крона + тихий зов»

Статус: **продуктовый wire/flow, 2026-08-07**.  
Код и UI не менялись. Это сценарий для следующей реализации поверх
существующего V5 API (`/api/v5`), без publication gate.

Связано с: `CHOSEN_DIRECTION_AB.md`, `V5_PRODUCT_SPEC.md`.

## 0. Цель документа

Зафиксировать, что человек видит и делает за **первые 2–3 минуты** от
открытия Mini App до видимого эффекта на дереве — и где мелькают мягкие
крючки, **не ломая соло**.

Критерий: после прохода владелец/игрок может сказать:

> Я Дятел; сегодня один держу Среднюю крону; за ~75 сек поставил щит;
> дерево изменилось; людей звать не обязан, но вижу тихий 2/4 и могу
> кинуть яйцо.

## 1. Карта экранов (первый заход)

Время — ориентир для новичка. Повторный заход короче (без претеста).

```text
0:00  Deep link / Mini App open
0:05  E0  Загрузка мира (крона, не спиннер-админка)
0:15  E1  Претест · 6 ситуаций          ~60–75с
1:30  E2  «Ты — Дятел» · выбор активной  ~15с
1:45  E3  Крона под угрозой (home)       ~10с  ← главный экран
       ├─ опц. E3a Яйцо-прогноз          ~10с  (если фаза прогнозов)
       └─ опц. E3b Тихий зов 2/4         glance
1:55  E4  Серия хода · 5 карточек        ~75с
3:10  E5  Удар по дереву (результат)     ~8с
3:20  E6  Home после хода                linger
       ├─ опц. share «посмотри дерево»
       └─ опц. встать в тихий сбор
```

Повторный день: `E0 → E3 → (E3a?) → E4 → E5 → E6`.

## 2. Экраны по шагам

### E0 · Загрузка мира

**Видит:** силуэт дерева / крона в тумане, без карточек и KPI.  
**Не видит:** «Dashboard», прогресс-бары профиля, нижнюю админ-навигацию.  
**Сервер:** текущий `GET /api/v5/state` (или эквивалент state bootstrap).

### E1 · Претест (только первый раз)

**Видит:** одна ситуация на весь экран; птица ещё не объявлена.  
**Делает:** 6 коротких выборов «как собираешь решение».  
**Тон:** профориентация как *способ думать*, не «кем тебе быть в ЦУ».  
**Сервер:** save pretest → `base_bird`.  
**Антифрустрация:** можно выйти; прогресс претеста не теряется, если API
уже это держит; иначе — явное «продолжить с вопроса N» в следующей
реализации.

### E2 · «Ты — [птица]»

**Видит:** крупно свою Form I птицу на фоне кроны + одна фраза роли:

| Птица | Одна фраза на экране |
| --- | --- |
| Дятел | «Ты собираешь цепочки и условия» |
| Сорока | «Ты делаешь выбор понятным человеку» |
| Сова | «Ты идёшь от гипотезы к факту» |
| Журавль | «Ты держишь порядок и ограничения» |

**Делает:** подтверждает активную птицу кампании (если ещё не зафиксирована).  
**Не делает:** не выбирает профессию, факультет, трек ЦУ.  
**Сервер:** active bird lock.

### E3 · Home · крона под угрозой (главный экран)

**Видит сразу (обязательный фокус):**

1. живое дерево;
2. **один** сектор под угрозой / законная цель окна (шторм или claim/hold);
3. свою птицу у этой ветки;
4. одну кнопку-жест: «Держать ветку» / «Открыть путь» / «Разведать»
   (по `action` сервера).

**Видит периферийно (мягкие крючки, не центр):**

- тихие искры/силуэты на секторах, где уже были чужие соло-вклады
  (без имён в лицо на первом заходе);
- если есть яйца и фаза прогнозов — компактный жест «Поставить яйцо»;
- если рейд открыт — маленький индикатор `2/4` у дупла, **не** модалка
  «Собери друзей!!!».

**Не видит на первом экране:** инвентарь-склад, линьку, длинную легенду
из четырёх KPI, очередь рейда на полэкрана.

**Серверные факты (уже есть в V5):** `map`, `objective`, `forecastDeadline`,
`raid.members`, `eggs`, `actionTaken`.

### E3a · Яйцо-прогноз (опционально, до первого влияющего хода)

**Когда:** `now < forecastDeadline` и есть ≥1 яйцо.  
**Видит:** один вопрос вида «Сектор N · claim — успеет / не успеет».  
**Делает:** тратит 1 яйцо → статус `pending`.  
**Уходит:** сразу назад на E3. Ход соло от этого не зависит.  
**Важно для новичка первого дня:** если яиц 0 (ещё не заработал) —
блок просто скрыт, без стыда и туториала «тебе нужно яйцо».

### E3b · Тихий зов (glance, не экран)

Не отдельная страница. На E3 у дупла: `2/4 · можно войти`.  
Тап → короткий sheet: «Рейд не обязателен. Соло-ход уже доступен.
Очередь растворится без наказания, если не наберётся 4».  
Кнопки: «Встать в очередь» / «Позже».

### E4 · Серия хода (~75 сек)

**Видит:** не «квиз в белой карточке», а серию **на ветке**: таймер и
прогресс карточек вшиты в сцену угрозы.

Состав 5 карточек (как в спеке, язык подачи новый):

1. микроскилл птицы (не эссе);
2. прикладной IT/учебный вопрос под птицу;
3–4. короткие развилки способа решения;
5. тактический жест = подтверждение `scout|claim|hold` на эту цель.

**Делает:** отвечает; сервер считает; один ход на окно.  
**Не делает:** не выбирает произвольную клетку карты ради оптимума —
цель уже объявлена сервером.  
**Сервер:** start series (+ optional item arm в одном batch) → submit.

### E5 · Удар по дереву (обязательный payoff)

**Видит 1–2 секунды анимации**, затем ясный факт:

- hold → на секторе появляется/усиливается щит-ward, туча слабеет;
- claim → сектор меняет состояние (`exposed → secured` и т.п.);
- scout → соседний сектор/риск раскрывается.

Плюс одна строка награды: «+1 перо пути» / «+1 яйцо» — **после** картины
мира, не вместо неё.

**Провал серии:** мир не «ломается персонально»; вклад слабый или нулевой,
но дерево остаётся общим; объясняется коротко: «удар не прошёл — ветка
без твоего щита».

### E6 · Home после хода

Тот же E3, но:

- кнопка хода disabled: «Ход окна уже сделан»;
- сектор показывает новый вид (доказательство);
- мягко доступны: тихий зов (если ещё открыт), share, линька только когда
  реально созрела (не пихать в первый заход).

**Share (игрок инициирует):** «Посмотри, что стало с кроной» → deep link /
картинка. Бот сам в чат не пишет.

## 3. Что специально откладываем с первого захода

Не показывать новичку в эти 2–3 минуты:

- полный инвентарь и выбор предмета (если без предмета можно стартовать —
  стартовать; иначе один слот «взять линзу?» максимум);
- Form II / линьку;
- длинную историю кампании;
- таблицу всех семи секторов как схему-админку;
- онбординг ЦУ / поступления.

## 4. Мягкие крючки и антиспам-лимиты

| Крючок | Где в UI | Лимит / правило |
| --- | --- | --- |
| Общее дерево | E3 / E6 всегда | следы анонимны или псевдоним птицы; без Telegram ID на карте |
| Чужие искры на секторе | E3 периферия | максимум несколько искр на сектор; без ленты «кто что сделал» |
| Яйцо-прогноз | E3a | 1 яйцо / исход; идемпотентный повтор; только до `forecastDeadline`; никогда на людей/сообщения |
| Тихий зов `N/4` | E3 glance | без автопуша в чат; sheet не чаще 1 раза за заход автоматически |
| Рейд 4–6 | sheet / E6 | не блокирует соло; <4 к дедлайну → dissolve без штрафа; потолок 6 |
| Share дерева | E6 | только по тапу игрока; шаблон без «срочности» и без @упоминаний |
| Publication / групповые посты бота | — | **выключены**; направление их не включает |
| Напоминания | вне первого захода | если когда-либо появятся — opt-in, не чаще 1/сутки, не про рейд |

### Антиспам чата (жёстко)

1. Бот не пишет в основной чат «зайдите в рейд / поставьте яйцо».
2. Бот не читает поток сообщений ради игры.
3. Единственный легитимный шум в чате на старте — то, что **человек сам**
   переслал share или админский arm/open в test-контуре.
4. Индикатор `2/4` живёт в Mini App, не в ленте Telegram.

### Антидот «никто не соберётся»

Игра всё равно работает: соло закрывает цикл. Социальный слой даёт
*дополнительный* смысл зайти («крона изменилась», «мой прогноз висит»,
«редко бывает 4/4»), а не условие доступа.

## 5. Соответствие текущему API (чтобы реализация не врала)

| Шаг сценария | Уже есть в V5 | Что меняется при UI-go |
| --- | --- | --- |
| E1 претест | да | визуальный язык, не схема анкеты |
| E2 птица | да | hero-reveal вместо карточки роли |
| E3 дерево+цель | map + objective есть | крона вместо node-graph dashboard |
| E3a прогноз | да, фаза до deadline | компактный жест, не отдельная «биржа» |
| E3b/рейд | queue есть | glance + sheet; не центр home |
| E4 серия | 5 cards + timer | сцена на ветке, не quiz-panel |
| E5 payoff | state update есть | **обязательная** анимация мира до чисел |
| следы стаи | частично через map progress | нужна явная «искра» в UI (может потребовать поле/агрегат; если нет — `UNKNOWN` до API) |

Если для искр чужих соло не хватает безопасного агрегата в state —
пометить `UNKNOWN` и не подставлять фейковые ники; до API можно показать
только суммарный прогресс сектора (уже есть).

## 6. Acceptance первого захода (ручной)

Закрытый test chat / test bot:

1. Новый пользователь проходит E1→E5 один, без второго человека.
2. После хода дерево визуально другое до чтения чисел награды.
3. При 0 яиц прогноз не блокирует и не стыдит.
4. Индикатор рейда можно игнорировать; соло-награда всё равно падает.
5. Бот не отправил в группу ни одного игрового пуша.
6. Игрок может уйти после E5 и завтра войти на E3 без претеста.
