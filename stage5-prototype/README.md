# Stage 5 — отдельный образец «Первая нить»

Это автономный образец одного пути:

> подготовить вопрос → увидеть пример отклика → подтвердить пользу → сохранить
> результат и следующий шаг

Он не связан с рабочим ботом, D1, Cloudflare или Telegram API и ничего не
отправляет наружу.

## Как открыть

Можно открыть `index.html` напрямую. Для проверки через локальный адрес:

```powershell
python -m http.server 4175 --directory stage5-prototype
```

Затем открыть `http://127.0.0.1:4175/`.

## Что проверяется

- понятен ли смысл первого действия без рассказа о продукте;
- помогает ли форма из трёх деталей улучшить вопрос;
- понимает ли человек, что отправка остаётся его действием;
- считываются ли четыре состояния птицы;
- понятна ли ценность личного сохранения результата;
- сколько времени занимает путь до финального состояния;
- сохраняется ли смысл при выключенном движении.

## Что намеренно отсутствует

- настоящая отправка в Telegram;
- авторизация и сохранение данных;
- рабочая база и сервер;
- второй сценарий помощи другому человеку;
- события, экономика, магазин, рейтинг и коллекция;
- полный набор птиц и экранов.

## Художественная основа

Принятое направление — «Карта сигналов». От первоначального листа сохранены
геометрическая графика, одна нить и четыре состояния. Птица сделана компактнее,
теплее и спокойнее.
