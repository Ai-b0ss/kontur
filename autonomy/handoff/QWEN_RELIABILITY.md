## Что уже есть

- локальные CAPTCHA/rate limit/expired auth не останавливают весь пул: бюджет переключений по умолчанию 4, жёсткий потолок 6;
- provider-wide WAF/trust restriction, provider pressure и неоднозначный timeout останавливают дальнейшее прощупывание соседних аккаунтов;
- новый независимый запрос выбирает давно не использовавшийся подходящий аккаунт, а существующий Qwen-тред сохраняет приоритет своего аккаунта-владельца;
- при failover незавершённой цепочки создаётся свежий Qwen-тред и один раз переносится полная локальная история;
- tool-loop продолжает работу после tool result и исправимых ошибок инструмента; обычный лимит 12 модельных ходов, жёсткий потолок 24;
- два режима системного промпта (`engineer`/`owner`) и локальные Skills уже есть;
- `provider-circuit.json`, account JSON, основной session checkpoint и backup сохраняются crash-safe;
- ChatGPT relay не активная задача до появления owner session; outbox не включать.

## Эта смена

- заново прочитаны owner intent, текущая карта и handoff; проверены PR #6 и `qwen-workspace` PR #5;
- перед изменениями PR #6 уже был на `2dd1ed39...`; после прошлого head `647ec7ad...` другой Qwen-рабочий менял только `server.js`, `src/agent.js`, `package.json` и агентные тесты, поэтому взят независимый `account-store`;
- найден реальный дефект удаления аккаунта: `remove()` сначала удалял аккаунт из памяти, а ошибку `unlink` полностью проглатывал. При ошибке диска вызов возвращал успех, но JSON оставался на диске и после restart аккаунт «воскресал»;
- исправлено: долговечное состояние удаляется первым; ошибка `unlink` теперь пробрасывается, а аккаунт остаётся в памяти. После успешного `unlink` на POSIX синхронизируется родительский каталог, затем запись удаляется из памяти;
- тест `scripts/account-store-persistence-test.js` теперь искусственно вызывает `EIO` на удалении и проверяет fail-closed, затем проверяет успешное удаление и отсутствие воскресшего аккаунта после `load()`;
- коммиты: `749a156fc2c00a7337b14760d6c9d6f96791c3b9`, `620d418cd1e1d73a42815ee2ff7899b810252a39`;
- provider traffic = 0; живые аккаунты, encrypted runtime, production и relay не тронуты.
